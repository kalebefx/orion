# Orion — Tech Stack

Documento de decisões técnicas do projeto Orion: sistema de gestão de rotina pessoal baseado em atributos.

## Gestão e planejamento

- **Trello** — Quadro de sprints semanais. Escolhido por ser visual, gratuito e muito usado no mercado para organizar tarefas em metodologia ágil.
- **draw.io** — Diagramas de classes e de fluxo do sistema. Gratuito, profissional e permite salvar os arquivos no repositório do GitHub.
- **Figma** — Protótipo das telas antes de construir o front. Padrão do mercado e evita retrabalho, como aconteceu no projeto do salão.

## Back-end

- **Java e Spring Boot** — API REST do sistema. Java é a linguagem do foco de carreira em back-end, e o Spring Boot é o framework mais usado no mercado para esse tipo de API.
- **PostgreSQL** — Banco de dados relacional. Gratuito, robusto e muito usado em produção, combina bem com JPA.
- **JUnit** — Testes automáticos da API. Garante que as regras de negócio continuam funcionando a cada mudança.
- **Postman** — Testar os endpoints da API durante o desenvolvimento, sem depender do front.

## Front-end

- **React** — Interface web do sistema. Escolhido para ganhar experiência numa segunda ferramenta além do Angular, já usado no projeto do salão, e por ser a mais pedida nas vagas júnior.

## Versionamento

- **Git e GitHub** — Controle de versão e portfólio público. Cada dia de estudo tem pelo menos um commit.

## Hospedagem

- **Railway** — Hospedagem do back-end em Java e do banco de dados.
- **Cloudflare Pages** — Hospedagem do front em React, gratuita e já usada no projeto do salão.
